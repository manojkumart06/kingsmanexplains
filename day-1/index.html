AI vs Machine Learning vs Deep Learning vs Generative AI

Four terms everyone mixes up, explained in one picture.

The one-picture summary

Think of four circles, one inside the other:

Artificial Intelligence
Machine Learning
Deep Learning
Generative AI

Every inner circle is a part of the one around it. Modern Generative AI is built with deep learning, which is a kind of machine learning, which is a kind of AI.

1. Artificial Intelligence (AI): the umbrella

Any technology that lets computers do tasks that normally need human intelligence: understanding language, recognising images, making decisions, playing games.

  • Old-school AI can be pure hand-written rules (e.g. a chess program following "if… then…" logic).
  • Everything below is a way of building AI.

2. Machine Learning (ML): learning from data

Instead of programmers writing every rule, the computer learns patterns from examples.

Traditional software Machine learning
Developer writes the rules Model learns the rules from data
if email contains "lottery" → spam Show it 100,000 spam / not-spam emails; it figures out the patterns
Breaks on cases nobody thought of Generalises to new, unseen cases

Typical jobs: predict a number, classify something, recommend an item.

3. Deep Learning (DL): neural networks

A type of machine learning that uses neural networks: many layers of simple "neurons", loosely inspired by the brain.

  • Each layer learns slightly more abstract patterns (edges → shapes → faces).
  • Needs lots of data and computing power (GPUs).
  • Powers speech recognition, image recognition and, importantly, today's Generative AI.

4. Generative AI (GenAI): creating new content

AI that creates brand-new content instead of only predicting or classifying.

It can generate: text (ChatGPT, Claude, Gemini) · images (Midjourney, DALL·E) · video · audio and music · code.

Under the hood, large language models are trained on huge amounts of text and generate an answer one word-piece (token) at a time, each time predicting what should come next.

The everyday example

Netflix recommendations ChatGPT
Type Machine learning Generative AI
What it does Predicts what you'll watch next Creates a brand-new answer
Output A ranked list of existing movies New text that didn't exist before

Remember this

Machine Learning predicts. Generative AI creates.

(Generative AI also learns patterns, but its job is to produce new content from them.)

Try it yourself (10 minutes)

  1. Ask ChatGPT, Gemini and Claude the same question: "Explain the difference between AI, machine learning, deep learning and generative AI to a 12-year-old."
  2. Compare the three answers. Which one is clearest? Did any of them get something wrong?
  3. Write your own 3-sentence explanation without looking.
