Fundamentals of Artificial Intelligence

AI, Machine Learning (3 types), Deep Learning, Generative AI and LLMs, explained simply.

1. What is Artificial Intelligence (AI)?

Definition:

Artificial Intelligence (AI) is a branch of computer science that enables machines to perform tasks that normally require human intelligence, such as learning, problem-solving, decision-making, understanding language and recognising images.

Examples:

  1. Voice assistants such as Siri.
  2. Chatbots such as ChatGPT.
  3. Facial recognition systems.
  4. Recommendation systems.
  5. Self-driving vehicle technology.

Applications of AI:

  • Healthcare
  • Banking
  • Education
  • Agriculture
  • Transportation
  • E-commerce
  • Customer service

2. What is Traditional Programming?

Traditional programming is an approach in which developers write specific instructions and rules for a computer to follow.

Example:

Imagine a developer wants to identify whether a customer is eligible for a discount. The developer writes a condition:

if (purchaseAmount >= 5000) {
    discount = 10;
} else {
    discount = 0;
}

The computer follows the rules written by the developer.

Basic working process:

Input + Instructions/Rules → Output

3. What is Machine Learning (ML)?

Definition:

Machine Learning is a subfield of Artificial Intelligence that enables computers to learn patterns from input data and make predictions or decisions without being explicitly programmed with every rule.

In Machine Learning, an algorithm learns patterns from data and produces a trained model.

Example: Email Spam Detection

Imagine we have 1,000 emails. Some emails are labelled as spam, while others are labelled as normal.

The Machine Learning model studies these examples and learns patterns associated with spam emails. When a new email arrives, the trained model predicts whether it is spam or not.

How Machine Learning works

  1. Data Collection: Collect relevant information.
  2. Data Preparation: Clean and organise the collected data.
  3. Model Training: Feed the data into an algorithm so it can learn patterns.
  4. Model Evaluation: Test the model to understand how accurately it performs.
  5. Prediction: Use the trained model to make predictions on new data.

Important Machine Learning terminology

  • Dataset: A collection of data used for training, validation or testing.
  • Algorithm: A mathematical method or procedure used to learn patterns from data.
  • Model: The result of training an algorithm using data. It can be used to make predictions.
  • Training: The process through which a model learns patterns from data.
  • Prediction: The output generated by a trained model for new input data.
  • Testing: Evaluating the model using data that was not used to train it.

4. Types of Machine Learning

There are three major types of Machine Learning:

A. Supervised Learning

Definition:

Supervised Learning is a type of Machine Learning in which a model learns from labelled data. The training data contains examples along with their correct answers.

The model learns relationships between inputs and known outputs and uses them to predict answers for new data.

Example: Email Spam Detection

Email Label
Win a free iPhone! Spam
Your bank statement Not Spam
Claim your prize! Spam
Meeting at 10 AM Not Spam

The model learns from these labelled examples and predicts the category of a new email.

Two common types of Supervised Learning:

  1. Classification: Predicts a category or class.
    • Spam or Not Spam.
    • Fraudulent or Genuine.
    • Cat or Dog.
  2. Regression: Predicts a numerical value.
    • Predicting house prices.
    • Estimating monthly sales.
    • Predicting temperature.

B. Unsupervised Learning

Definition:

Unsupervised Learning is a type of Machine Learning in which a model learns from unlabelled data and identifies patterns, similarities or groups without predefined target answers.

Example: Customer Segmentation

Imagine an online shopping company has information about 1,000 customers, including their shopping history and spending habits. The company has not assigned any customer groups.

The model analyses the information and groups customers with similar shopping behaviour. Possible groups:

  • High-spending customers.
  • Regular customers.
  • Occasional customers.

Common techniques:

  1. Clustering: Groups similar data points together.
  2. Dimensionality Reduction: Reduces the number of features while retaining important information.

C. Reinforcement Learning

Definition:

Reinforcement Learning is a type of Machine Learning in which an agent learns by interacting with an environment and receiving rewards or penalties for its actions. The agent gradually learns which actions are more beneficial.

Example: Teaching an AI to play a game

  1. The AI performs an action.
  2. The game responds to that action.
  3. The AI receives a reward or penalty.
  4. It learns from the result.
  5. It tries to improve its future actions.

Important terminology:

  • Agent: The learner or decision-making system.
  • Environment: The world in which the agent operates.
  • Action: What the agent does.
  • Reward: Feedback received after an action.
  • Policy: The strategy used by the agent to choose actions.

Difference between the three types

Supervised Unsupervised Reinforcement
Uses labelled data Uses unlabelled data Learns through interaction
Correct answers are provided No predefined target answers Receives rewards or penalties
Predicts known targets Discovers patterns and groups Improves its actions
Spam detection Customer grouping Game-playing AI

Easy way to remember:

  • Supervised = Learning with answers.
  • Unsupervised = Learning without predefined answers.
  • Reinforcement = Learning through rewards and penalties.

5. What is Deep Learning (DL)?

Definition:

Deep Learning is a subfield of Machine Learning that uses artificial neural networks with multiple layers to learn complex patterns from large amounts of data. It is inspired by some of the information-processing principles of the human brain.

What is a Neural Network?

A Neural Network is a computational model made up of interconnected units called artificial neurons. These neurons are organised into layers that process information.

Three main layers

  1. Input Layer: Receives the input data.
  2. Hidden Layers: Process information and learn patterns.
  3. Output Layer: Produces the result.

Example: Image Recognition

Imagine you give a computer thousands of pictures of cats and dogs. A Deep Learning model learns patterns from these pictures, such as shapes, textures and visual features.

When you provide a new picture, the model can predict whether it contains a cat or a dog.

Applications of Deep Learning:

  • Face recognition.
  • Speech recognition.
  • Image classification.
  • Language processing.
  • Medical image analysis.

6. What is Generative Artificial Intelligence (GenAI)?

Definition:

Generative AI is a category of AI systems that can generate new content, such as text, images, audio, video and computer code, based on patterns learned from training data.

Unlike systems that only classify or predict, Generative AI can produce new outputs.

Examples:

  1. ChatGPT generates text and code.
  2. Gemini can understand and generate content.
  3. Image-generation tools create images from text prompts.
  4. AI video tools generate videos.
  5. AI music tools generate audio.

How Generative AI works (simplified)

  1. The model is trained using large amounts of data.
  2. It learns patterns and relationships within that data.
  3. A user provides a prompt.
  4. The model processes the prompt.
  5. It generates an output based on what it has learned.

Applications of Generative AI:

  • Content creation.
  • Image generation.
  • Video generation.
  • Code generation.
  • Chatbots.
  • Document summarisation.
  • Software development.
  • Customer support.

7. What is a Large Language Model (LLM)?

Definition:

A Large Language Model (LLM) is an AI model trained on large amounts of text data to understand and generate human-like language.

LLMs are commonly used for answering questions, writing content, summarising documents, generating code and conversational applications.

Examples:

  • OpenAI GPT models.
  • Google Gemini models.
  • Anthropic Claude models.

How does an LLM work?

At a simplified level:

  1. The user provides a prompt.
  2. The text is converted into tokens.
  3. The model processes the tokens and context.
  4. It predicts likely next tokens.
  5. The model generates a response token by token.

Example:

Prompt: "Artificial Intelligence is..."

The model uses the context and its learned patterns to generate a suitable continuation.

Important: An LLM does not think or understand exactly like a human. It processes information using mathematical patterns learned during training.

8. Important LLM Terminology

  1. Prompt: An instruction or input provided to an AI model to perform a task. Example: "Explain Machine Learning in simple English."
  2. Token: A small unit of text processed by a language model. A token can represent a word, part of a word or punctuation.
  3. Context Window: The amount of information a model can process and consider within a particular interaction.
  4. Hallucination: When an AI model generates information that sounds convincing but is incorrect, unsupported or fabricated.
  5. Foundation Model: A large model trained on broad datasets that can be adapted for different tasks.
  6. Multimodal AI: AI that can process or generate different types of information, such as text, images, audio and video.

11. Real-world Applications of AI

  1. Banking: Detecting suspicious transactions.
  2. Healthcare: Analysing medical images.
  3. E-commerce: Recommending products.
  4. Education: Personalised learning assistance.
  5. Agriculture: Crop monitoring and disease detection.
  6. Transportation: Traffic prediction.
  7. Customer Support: Answering customer enquiries.
  8. Software Development: Generating and explaining code.

12. Limitations of Generative AI

  1. Hallucinations: AI can generate incorrect information.
  2. Bias: Models may reproduce biases present in training data.
  3. Privacy: Sensitive information should not be entered into tools without checking their data policies.
  4. Accuracy: AI-generated answers need verification.
  5. Context: Models have limits on the amount of information they can process.
  6. Reliability: AI-generated code and decisions need testing and human review.
